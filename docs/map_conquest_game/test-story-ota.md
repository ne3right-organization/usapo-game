# テストストーリー: 伊能忠敬、大田区を征く

12個のモックを、大田区（東京都13・cityCode 111）を軸にした一続きの物語としてレビューするためのウォークスルー。各章の数字は実データで実際に検証済みの値（`docs/map_conquest_game/README.md`の暫定計算式をそのまま適用）。乱数が絡む部分（サイコロ・CPU縄張り抽選）以外は、書いてある通りの結果になるはず。

前提: ローカルサーバー（`http://localhost:3000/` など）でこのフォルダを配信した状態で開く。都道府県は基本すべて「13 東京都」を選ぶ（devにデータがフル対応しているのがここだけのため）。

---

## 第1章 属性を知る — attribute-map-mock.html

1. 東京都 → 大田区（111）を読み込む。全220町丁目（水面除外後）。
2. 「田園調布南」を探す。大田区の田園調布7町丁目の中で**唯一の水属性**（守備力2462・人口3803）。本町・一〜五丁目は地または火のまま（僅差ではあるが水は逆転しない）。
3. 「羽田空港三丁目」（1012ha・人口0）と「城南島一丁目」（12ha・人口0）を確認 → どちらも地属性。人口ゼロの巨大インフラは、この4属性モデルでは森林と区別がつかないという既知の限界がそのまま見える。

## 第2章 歩き出す — movement-phase-mock.html

1. 大田区を読み込み、「城南島一丁目」をクリックして開始地点にする（実際に大田区内で守備力最弱の町丁目）。
2. サイコロを振って城南島二〜七丁目・平和島・京浜島あたりを回ってみる。分岐点（複数候補）で足跡と分岐選択UIが機能するか確認。

## 第3章 挑む — battle-phase-mock.html

1. 大田区を読み込む。開始拠点は自動的に「城南島一丁目」（守備力48）になる。
2. 初期デッキ（無属性4枚+古木の番人、合計485〜515）のままだと、隣接フロンティア（平和島三丁目・城南島二・三丁目など）はだいたい勝率80%超になるはず。
3. 「🎯 このデッキで勝てそうな場所」に城南島・平和島・京浜島系が並ぶことを確認。

## 第4章 テンポよく — integrated-loop-mock.html

1. 同じ大田区・同じ開始拠点で、今度はサイコロ移動→遭遇→戦闘→次のターン、のテンポで数ターン回す。
2. ターン数・占領数が右上に増えていくのを確認。

## 第5章 カードを得る — card-acquisition-mock.html

1. 大田区を読み込む。
2. 「羽田空港三丁目」をクリック → **属性カード（地）とアクセス系カード（空港ワープパス）が同時に獲得演出**されるはず（羽田空港一・二・三丁目のどれでも同様）。
3. 続けて「城南島一丁目」をクリック → 地属性カードは既に持っているので、新規獲得なしのトースト通知になるはず。

## 第6章 育てるか、放置するか — occupation-investment-mock.html

1. 大田区を読み込み、城南島一丁目付近を2〜3タイル占領する。
2. 1つは「投資する」、もう1つは「放置する」に設定して「次のターンへ」を数回押す。投資側の守備力バーが伸び、放置側が縮んでいくのを確認。
3. 収入/維持費/収支の表示（属性ごとの傾斜: 地は低収入低維持費）も確認。

## 第7章 季節を巡る — tourism-mock.html

1. 大田区を読み込み、いくつか町丁目を占領する。
2. 「この市区町村は観光地」をONにして「次のターンへ」を4回押し、春→夏→秋→冬と巡らせる。夏（×1.6）で実収入が跳ね、冬（×0.7）で落ち込むのを確認。
3. OFFに戻すと季節による変動が消えることも確認。

## 第8章 空を飛ぶ、島を渡る — movement-cards-mock.html

1. 大田区を読み込み、「✈️ 空港ワープパス」をONにする → 羽田空港一・二・三丁目の3タイルが紫の点線で直結される。
2. 「🏝️ 離島の渡し船」をONにする → 平和島・昭和島・城南島・京浜島・令和島系の20タイルが8km圏内でほぼ全部相互接続される（190本）。開始地点を城南島にして、この特殊ルートで一気に京浜島へワープできるか試す。
3. 「⛴️ 港町のフェリー券」は**大田区には該当する町丁目が無いため確認できない**（`/(?<!空)港/`にマッチする地名が0件）。試すなら別の区（港区など「港」を含む地名が多そうな区）で。

## 第9章 縄張り争い — rival-territory-mock.html

1. 大田区を読み込む（約44町丁目=220×20%がランダムでCPU縄張りになる。読み込みごとに変わる）。
2. 紫のCPU territoryが自分のフロンティアに現れたら、「通行料を払う」と「奪還を狙う」の両方を試す。奪還の守備力はCPU分+30%されている。

## 第10章 特別なカード — card-categories-mock.html

1. 大田区を読み込む。⭐マーカーは**「下丸子二丁目」**（人口10,376・大田区内最大）に立つはず。
2. ⭐をクリックして「町丁目人口王の証」獲得の演出を確認。
3. 右パネルのサイコロ操作系・経済系・拠点強化系のミニデモもそれぞれ触ってみる（これらは地図と連動しない単体デモ）。

## 第11章 東京都を俯瞰する — macro-structure-mock.html

1. 東京都を読み込む（62市区町村、進捗バーが出て少し時間がかかる）。
2. 開始拠点は**「瑞穂町」**（本土側で守備力最弱・32,528）になるはず。離島9村（利島村など）は守備力自体はもっと低いが、陸続きでないため連結成分から除外され、開始拠点候補から外れる。
3. **大田区は62市区町村中61位（守備力498,038）で、世田谷区に次いで2番目に手強い**——設計書が意図する「地方から始めて都心がラスボス」という難易度カーブが、この暫定式でもそのまま体感できる。瑞穂町から歩いて大田区に辿り着くのは長い道のり。
4. 隣接する市区町村（羽村市・日の出町など）を占領して、侵入口（境界を接する町丁目）が動的に決まる様子を確認する（大田区まで行かなくてもこの章の検証としては十分）。

## 第12章 本命: 全部繋げる — macro-micro-integrated-mock.html

1. 東京都を読み込み、瑞穂町からスタート。隣接する市区町村をクリック → 侵入口が決まり、ミクロ画面（町丁目レベルのサイコロ移動＋戦闘）に自動的に切り替わることを確認。
2. ミクロ画面で数タイル攻略したら「🗾 マクロ画面に戻る」で確保 → 隣接する次の市区町村が解放される、という往復を2〜3回試す。
3. **正直な注意点**: 大田区は本土最弱の瑞穂町から見て隣接ロックの奥のほうにあるため、実際に歩いて大田区まで辿り着くのは何十ターンもかかる長い道のりで、数分のスモークテストでは終わらない。この章では「往復ループの仕組みそのものが動くか」を、瑞穂町周辺の到達可能な市区町村で確認すれば十分。大田区そのものへの到達は、腰を据えた通しプレイ向けの検証として別途どうぞ。
4. （既に確保済みの市区町村は再クリックでミクロ画面に戻れるので、瑞穂町のミクロ攻略を後からやり直したい場合もこれで戻れる。）
