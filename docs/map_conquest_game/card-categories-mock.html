🏆 統計連動レアカード

実績連動。設計書の例「人口日本一の町丁目占領」は全国データが必要なため、このモックでは「読み込んだ市区町村内で人口最大の町丁目」に縮小して実データで検証する。
町丁目人口王の証
読み込んだ市区町村内で人口最大の町丁目を占領すると手に入るレアカード
