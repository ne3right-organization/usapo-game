🗺️ 地図制覇ゲーム モック集

map_conquest_game_design.md の内容を検証している、単体HTMLの動くプロトタイプ一覧です。
各モックはブラウザで直接開くだけで動く自己完結HTML。実データ（国土数値情報・国勢調査の町丁目境界）を直接CloudFrontから取得します。
データソース・計算式・既知の限界などの詳細は README.md を参照してください。

🎨

属性マップ

町丁目ごとの火・水・地・風の4属性を、面積・人口密度・形状などの実統計データから機械的に算出して色分け表示する。

地 火 風 水
🎲

移動フェーズ

サイコロを振って隣接町丁目を辿る移動。分岐点でのルート選択UI、歩いたルートの足跡表示を検証する。

移動
⚔️

戦闘フェーズ

隣接ロック下で攻略可能な町丁目を選び、守備力・デッキ5枚の攻撃力・事前勝率を提示。挑戦→サイコロ補正→勝敗→占領/資金増減までの一連の流れ。

戦闘デッキ
🔁

統合ループ

移動フェーズと戦闘フェーズを1本に統合。サイコロで移動→未攻略地に着地したら戦闘発生→「次のターンへ」で明示的に区切るテンポを検証する。

移動戦闘
🎴

カード獲得演出

占領した瞬間のカード獲得演出（3Dカードフリップ）の単体検証。属性カードとアクセス系カード（離島/フェリー/飛行機）の獲得を確認できる。

カード
🏯

占領地の二層構造

占領直後は基礎値のみ。ターンを進めながら「投資する/放置する」を選び、守備力ボーナスが積み上がる・減衰する様子と、属性別収入・維持費の収支を検証する。

経済
🗾

市区町村マクロ構造

市区町村単位での攻略・隣接ロック。占領すると、直前にいた自治体と実際に境界を接する町丁目を探して「侵入口」を動的に決定する。

マクロ
🌸

観光要素

市区町村単位の観光地フラグと季節倍率（春夏秋冬）を占領地の収支に重ねる。観光地ONだと夏に収入が跳ね、冬は落ち込む。

経済
🏝️

移動手段の進化

離島の渡し船・港町のフェリー券・空港ワープパスを所持すると、名前パターン一致の町丁目同士に特殊ルートが開通し、サイコロ移動でワープできる。

カード移動
👑

他プレイヤーの占領地

読み込んだ町丁目の約2割をCPUの縄張りとしてランダム割当（守備力+30%）。隣接すると通行料を払うか奪還を狙うか選べる。

CPU戦闘
🃏

カードカテゴリ4種

サイコロ操作系・経済系・拠点強化系・統計連動レアの4カテゴリをミニデモで単体検証。統計連動レアは読み込んだ市区町村の実データと連動。

カード
🧭

マクロ⇄ミクロ統合

市区町村マクロ構造と移動+戦闘の統合ループを接続した本命モック。侵入口から町丁目攻略→区市町村を確保→次の区市町村が解放、という往復ループの通し検証。

マクロ統合
すべて usapo.net本体の `docs/sample/` と同じ流儀（プロキシなし・CloudFrontから直接fetch）の使い捨てプロトタイプです。
本番想定はスマートフォンでのプレイですが、これらのモックはデスクトップ・マウス操作前提のレイアウトです。
