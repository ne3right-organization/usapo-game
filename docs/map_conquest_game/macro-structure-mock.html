市区町村の守備力は町丁目データを集計した人口・面積から算出（人口密度が高いほど強い＝地方→都心の難易度カーブ）。
隣接する市区町村を占領すると、直前にいた区市町村と実際に境界を接する町丁目が「侵入口」として動的に決まる。
