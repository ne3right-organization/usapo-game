占領地の二層構造

投資中（守備力が育つ）
放置中（守備力が減衰）
未占領（クリックで占領デモ）
実効守備力 = 基礎値 ×(1+投資ボーナス)。投資し続けるとボーナスが積み上がり、放置すると徐々に基礎値まで戻る。
収入は占領地なら投資中/放置中問わず毎ターン入る（火・風は高収入高維持費、地は低収入低維持費、水は中程度安定）。
拡張型: 広く浅く（投資せず数で稼ぐ） / 拠点型: 少数に厚く投資 / ハイブリッド型: 使い分け
出典: 国土数値情報・国勢調査（2020年）小地域集計
投資/減衰の増減率・維持費はこのモック独自の暫定値（要調整）
