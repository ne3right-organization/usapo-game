# 地図制覇ゲーム 設計書(仮)

## コンセプト

実データ(国土数値情報・stat.usapo.netの統計API)を使い、日本全国を歩いて制覇していくカルドセプト風の陣取りゲーム。伊能忠敬のように、徒歩から始めて日本地図を踏破していく物語性を持たせる。

## 基本フォーマット

- 非同期対戦(実質はCPU = 統計データ由来の守備力相手の攻略がメイン)
- 占領状態は恒久的(シーズンリセットなし)

## 攻略構造(二段階の入れ子)

- **大枠**: 市区町村単位で攻略ルートが進む、隣接ロックあり
- **内部**: 各市区町村の中は町丁目単位でさらに攻略、こちらにも隣接ロックあり
- **侵入口**: 固定でなく、直前にクリアした隣接自治体との境界の町丁目から動的に決まる(実際に歩いてきたルートが反映される)
- **難易度分布**: 人口密度・産業集積が高いほどCPUが強い → 地方から始めて東京23区などがラスボス的位置づけになる自然な難易度カーブ

## 移動フェーズ

- サイコロを振り、出目の数だけ隣接町丁目を辿って移動
- 分岐点(隣接候補が複数)では進行方向をプレイヤーが選択(通行料回避などのルート戦略が生まれる)
- 移動手段は段階的に進化:

| 段階 | 入手条件 | 効果 |
|---|---|---|
| 徒歩(初期、伊能忠敬モチーフ) | 初期状態 | 陸続きの隣接町丁目のみ移動可能 |
| 橋・トンネルカード | 該当地区(本土側)を攻略 | 地続き化、以後は徒歩感覚で渡れる(例:瀬戸大橋、関門トンネル) |
| フェリーカード | 港町を攻略 | 対岸・離島への航路が開通 |
| 飛行機カード | 空港のある地区を攻略 | 空港同士を一気にワープ |

## 戦闘フェーズ

- **デッキ構築**: 持ってるカードから5枚選んでデッキを組んで挑む
- **守備力**: 人口密度・面積などから算出したインフラ維持コストがそのまま守備力になる(インフラ経済システムと数値の出どころが一貫)
- **勝敗判定**: 事前に勝率を提示し、挑戦するか選択できる。戦闘時は別途サイコロを振り、出目で確率が変動(移動用のサイコロとは独立)
- **敗北ペナルティ**: 資金(インフラ維持予算)が減る
- **演出**: 絵は使わず、数値・属性アイコン・簡易アニメーションのみで表現、制作コストを抑える
- 他プレイヤーの占領地に止まったら、通行料を払うか奪還を狙うか選べる

## 土地の個性(属性システム)

火・水・地・風の4属性を、面積・形状(コンパクト比)・人口密度など既存の境界データ+統計データから機械的に算出(新規データ取得なし)。

| 属性 | 判定条件 | イメージ |
|---|---|---|
| 地 | 面積が大きく、人口密度が低い | 森・農地 |
| 火 | 面積が大きく、形が単純(コンパクト比が高い) | 工業地帯 |
| 風 | 面積が小さく、人口密度が高い | 駅前・都市中心部 |
| 水 | 中程度の面積、世帯当たり人数が多い/持ち家率が高い | 一軒家の住宅地 |

- 攻撃側の属性と土地の属性が合うとボーナス
- 判定が複数属性にまたがる場合は、4属性のスコアを算出し最も高いものを採用(複合スコア方式)

## 先行者有利対策(占領地の二層構造)

```
占領地の守備力 = 統計データ由来の基礎値 × (1 + プレイヤーの投資によるボーナス)
```

- 占領した瞬間は基礎値のみ(まだ薄い占領状態)
- 維持コストの支払い・継続的な投資によってボーナスが積み上がり、守備力が上がる
- 投資をやめる/維持コストを払えなくなるとボーナスは徐々に減衰し、最終的には基礎値(=未占領地相当)まで戻る

**プレイスタイルの分岐**
- 拡張型:広く浅く取って通行料収入を稼ぐ(ボーナスは薄く、奪還されやすい)
- 拠点型:少数の土地に厚く投資して鉄壁の拠点にする
- ハイブリッド型:広く取りつつ、要所(侵入経路上の土地など)だけ厚く守る

## インフラ経済システム

- 維持コスト(維持予算)を攻撃リソース(遠征ポイント)とは別経済圏として管理
- 属性ごとに収入・維持コストの傾斜をつける:

| 属性 | 収入源 | 特徴 |
|---|---|---|
| 火(工業) | 製造業からの固定収入 | 高収入・高維持コスト |
| 地(農地・森林) | 収入は少ない | 低収入・低維持コスト(安全資産) |
| 風(商業・都市) | 通行料が主力収入 | 高収入・高維持コスト、競争が激しい |
| 水(住宅) | 中程度で安定 | バランス型 |

- 過疎地を広く取ると収入が薄く維持費だけかさむ、都市部は稼げるが競争が激しい、という実際の自治体財政構造を反映

## 観光要素

- 既存4属性とは別に「観光地フラグ」を重ねる形で実装(新規データ判定が必要な独立属性化より軽量)
- 観光地は季節・インバウンド動向に応じて収入倍率が変動(繁忙期ブースト/閑散期は通常以下)
- データ粒度の都合上、観光ブーストは**市区町村単位で一括適用**(町丁目属性とは別レイヤー)
- 段階的実装:まずは固定の季節倍率(春夏秋冬)から始め、余裕があれば実観光統計と連動

## カードシステム

カードは盤面に置く駒ではなく、**プレイヤーに紐づく常時発動の装備**として扱う。

- 攻略した土地の特性に応じて対応カードが手に入る(例:離島攻略→離島カード、港町攻略→フェリーカード)

**カテゴリ**
1. アクセス系(地形突破、必須系):離島カード、飛び地カード、乗り物カード等
2. 属性強化系:特定属性への攻撃/守備ボーナス
3. サイコロ操作系:出目補正、振り直し等
4. 経済系:通行料免除、収入ブースト等
5. 拠点強化系:個別配置可能、拠点の守備力・収益を底上げ
6. 統計連動レアカード:実績連動(例:人口日本一の町丁目占領など)

## データソース

- 国土数値情報(境界ポリゴン、道路・海岸線データ)
- stat.usapo.net 統計API(人口密度、高齢化率、産業構造等)
- 離島・橋梁・空港などのアクセス系データは手動リサーチ(規模は数百件程度、有名どころから段階的に追加)
