# うさぽ農園 アイテムの絵の作り方（画像生成AI）

うさぽ農園（旧称: 地図タネ）のアイテム（タネ・実・ガーデンに飾るもの）の絵を、画像生成AIで作る手順。考え方は [全体設計書](地図タネ_全体設計書.md) の10章、絵の条件は [初期試作設計書](地図タネ_初期試作設計書.md) の10章にある。

- アイテムは 5コース × 10種類 × 3つ ＝ **150点**。定義は `src/lib/game/chizuTane/courses.ts`、一覧は管理ページ `/admin/chizu-tane/items`
- 絵ができるまでは絵文字を出している。絵を足すと、集めたもの・ガーデン・タネの絵・管理ページにそのまま出る
- **先に作るのは、いまの試作で使う Lv.1〜3 の45点**（下の作業表で ★ のシート）

---

## 0. 使う道具

**ChatGPT か Gemini の画像生成**を使う（準備がいらず、見本の画像に絵柄を合わせてくれる）。途中で道具を変えると絵柄がずれるので、**最初に決めた道具で最後まで作る**。

| 道具 | 背景の透明化 | メモ |
|---|---|---|
| ChatGPT | 「背景を透明に」と頼めば透過 PNG で出ることが多い | 会話で直しを頼みやすい |
| Gemini | 白背景で出ることが多い → 後で透明にする（手順3） | 見本に合わせるのが得意 |

権利の注意:

- 作った絵は公開サイト（game.usapo.net）と公開リポジトリに置く。各サービスの規約で、生成した画像を公開・利用してよいことを確かめておく
- **実在の商品・キャラクター・ロゴに似せない**。例えばドクターイエローは「黄色い新幹線の検測車」として描かせ、会社のロゴや車両番号は入れない。お城・神社も特定の場所に似せない

## 1. 絵の決まり（全部の絵で共通）

| 項目 | 決まり | 理由 |
|---|---|---|
| 視点 | 斜め上から見下ろす（45度くらい）。正面やま横から描かない | ガーデンが斜め上から見た箱庭なので |
| 絵柄 | かわいいミニチュア風（ころんとした形、柔らかい色、細い線は使わない） | 子どもにも分かりやすく、並べたときにそろう |
| 形 | **シルエットだけで見分けられる**形。細かい描き込みはしない | ガーデンの1マスはスマホで30px前後まで小さくなる |
| 光 | 左上から当たる | 全部の絵でそろえる |
| 影・地面 | **描かない**（足元の影・台座・草地も無し） | 影はゲームの側で付けている（`GardenSvg.tsx`） |
| 背景 | 透明（透明にできなければ真っ白の無地） | 切り抜いて置くため |
| 置き方 | 1点が正方形の中に収まり、下端の中央が「地面に接する点」 | ガーデンでマス目の地面に立たせるため |
| 文字 | 入れない（看板の文字・ロゴ・数字も無し） | 小さいと読めず、権利の心配もある |

## 2. 手順

### 手順1: 絵柄の見本（標準デザイン）を1枚作る

各コースの Lv.1 から代表を選び、**1枚の絵にまとめて**描かせる（1枚にまとめると絵柄が自然にそろう）。気に入るまで会話で直し、できた絵を「標準デザイン」として保存する（ファイル名 `style-reference.png`）。

```
ゲーム用のアイテムの絵を、3×3 のマス目に並べた1枚の画像で作ってください。

【絵の決まり】
- かわいいミニチュア風。ころんとした形、柔らかいパステル寄りの色、太めのシンプルな輪郭
- 斜め上（45度くらい）から見下ろした視点
- 光は左上から。足元の影・台座・地面・草は描かない
- 背景は透明（無理なら真っ白の無地）
- 1マスに1点。マスの中央に置き、下端の中央が地面に接するように
- 小さく表示してもシルエットで見分けられる形。細かい描き込みはしない
- 文字・ロゴ・数字は入れない

【並べるもの（左上から右へ）】
1. みかんの木（実のなった小さな木）
2. すずめ
3. 一眼レフカメラ
4. 自転車
5. 食パン
6. チューリップ
7. ウサギ
8. 路線バス
9. パン屋さん（小さなお店の建物）

English keywords: cute miniature game item icons, isometric top-down 45 degree view,
soft pastel colors, simple bold outlines, no shadow, no ground, transparent background,
3x3 grid, one item per cell, centered, no text
```

直すときの頼み方の例:

- 「もっと丸っこく、線を太く」「色を少し落ち着かせて」
- 「全部の視点をそろえて。自転車がま横からになっているので斜め上からに」
- 「影と地面を消して」

### 手順2: 見本を付けて、残りを作る

**毎回、標準デザインの画像（`style-reference.png`）を添付して**、下のひな形に作業表のシートの中身を入れて頼む。1回で1シート（1種類3つ × 3種類 ＝ 9点）。

```
添付した画像と同じ絵柄で、ゲーム用のアイテムの絵を 3×3 のマス目に並べた1枚の画像で作ってください。
視点・線の太さ・色合い・光の向きを添付の画像にそろえてください。

【絵の決まり】
- 斜め上（45度くらい）から見下ろした視点。光は左上から
- 足元の影・台座・地面・草は描かない。背景は透明（無理なら真っ白の無地）
- 1マスに1点。マスの中央に置き、下端の中央が地面に接するように
- 小さく表示してもシルエットで見分けられる形。文字・ロゴ・数字は入れない

【並べるもの（1行に1種類、左から右へ）】
（ここに作業表のシートの中身を貼る）
```

コツ:

- 1シート作るたびに、見本と並べて見比べる。ずれていたら「添付の見本と比べて○○が違うので直して」と頼む
- 会話が長くなると絵柄がずれやすい。**数シートごとに新しい会話**にして、見本を付け直す
- 3つ目ほど「目玉」になるように、1行の中で左から右へ少しずつ立派にする（建物コースは3つ目が建物そのもの）

### 手順3: 置いてスクリプトを動かす

1. できた画像を置く（元の画像は大きいので git には入れない）
   - シート: `art/chizu-tane/sheets/{シートID}.png`。シートID は作業表の見出しのもの（植物-1 → `plant-1.png`、動物-1 → `animal-1.png`、趣味 `hobby-`、乗り物 `vehicle-`、建物 `building-`）
   - 1点だけ作り直したもの: `art/chizu-tane/singles/{アイテムID}.png`（例: `orchard_1.png`）
2. スクリプトを動かす

   ```
   npx tsx scripts/chizu-tane/process-item-images.mts            # 置いてある画像を全部
   npx tsx scripts/chizu-tane/process-item-images.mts plant-1    # シート・アイテムを指定して
   ```

スクリプト（`scripts/chizu-tane/process-item-images.mts`）がすること:

- 背景が白なら、外側からつながっている白を透明にする（すでに透明ならそのまま）
- 絵のかたまりを見つけ、中心がどのマスにあるかで各アイテムに振り分ける（マス目が少しずれていてもよい。隣のマスからのはみ出しは入らない）
- 余白を切り詰め、**96×96**（表示は 48px 前後なので2倍）に収めて、下端の中央が地面に接するよう下に寄せる
- `public/chizu-tane/items/{アイテムID}.png` に保存し、絵のあるアイテムの一覧（`src/lib/game/chizuTane/itemImages.generated.ts`）を作り直す

うまくいかないとき:

- 「マスに絵が見つかりません」: そのマスが空か、絵が白っぽく背景と一緒に消えた。背景を透明にしてもらうか、その1点を `singles/` で作り直す
- 1つの絵が2つのマスにまたがっている・余計なものが入る: その1点を `singles/` で作り直す
- 白い部分（白鳥・白いサギなど）が消える: 外側とつながった白は背景として消えるので、輪郭で囲まれるよう描いてもらうか、背景を透明にしてもらう

### 手順4: ゲームで確かめる

1. 一覧（`itemImages.generated.ts`）に載ったアイテムは、自動で絵文字の代わりに絵が出る（`courses.ts` の `imageUrl` になる。手で書き足さなくてよい）
2. 管理ページ `/admin/chizu-tane/items` で、ほかの絵と並べて見比べる。ガーデン（`/game/chizu-tane/garden`）にも置いてみる
3. 確かめること（初期試作設計書 10.3）:
   - 背景が透明か、輪郭がはっきりしているか
   - 小さくしても見分けられるか
   - 視点・光の向きがほかの絵とそろっているか
   - 大きさや余白が極端に違わないか
4. 浮いている絵だけ作り直す
5. コミットするのは `public/chizu-tane/items/` と `itemImages.generated.ts`
