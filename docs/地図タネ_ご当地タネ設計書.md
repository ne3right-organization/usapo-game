# うさぽ農園 ご当地タネ 設計書

2026-10-30 の壁打ちで決めた、都道府県ごとの「ご当地もの」の設計。まだ作っていない（本番リリースのあとに作る）。全体のルールは `地図タネ_全体設計書.md`。

## 1. ねらい

- うさぽ農園の中心は「訪ねること」。**そこに行かないと手に入らないもの**があると、旅行やお出かけがそのまま遊ぶ理由になる
- 旅行先で手に入れ、地元に持ち帰って近所の人に配る、という流れで、人とのつながりも広がる
- 47都道府県ぶんそろうと壮観。ただし遊ぶ人の多くは首都圏なので、全部そろう人はまずいない。「旅行に行くたびに1つ増える」くらいの楽しみ方を想定する

## 2. コースの表での位置（決定）

- **各コースの Lv.10 の次に「ご当地」の段を置く**。1つの都道府県につき、コースごとに3つ（1個目・2個目・3個目）。全部で 5コース × 3 × 47 = 705 点
- 拠点の種類としては、コースごとに「ご当地の畑」が1つ（例: 植物コースのご当地の畑）。置かれるものが都道府県で変わる
- 例: 北海道の果樹園＝夕張メロン、神奈川＝湘南ゴールド、田んぼなら各地のブランド米
- **乗り物はその土地ならではの交通**（路面電車・ロープウェイ・ケーブルカー・人力車・渡し船・屋形船・雪上車・水牛車など）。**実在の会社・車両の名前やデザインは使わない**（「路面電車」のような一般的な名前にする）。地域ブランドの名前（夕張メロンなど）は使ってよいが、ロゴやパッケージは描かない
- 量が多いので、はじめは絵文字と名前だけで出し、絵は少しずつ足す。都道府県もそろってから出すのではなく、用意できたところから出してよい
- ID は `orchard_p01` のように都道府県コード（01〜47）を付ける形（案）。アイテムは `baseTypeId` を自分で持っているので、ID の形が `${baseTypeId}_${rank}` と混ざってもよい
- ご当地のものには都道府県の印（例: `local: "01"`）を付け、**レベルアップの条件（その種類のタネを全部まく）には入れない**。集めたものの一覧では、レベルの上限（本番 Lv.3）に関係なく出す

## 3. ご当地のタネの手に入れ方（決定）

- **もらえるのは自分のコースのものだけ**
- 1人1都道府県につき、1個目 → 2個目 → 3個目の順に1つずつ。それぞれ1回だけ
- **ご当地の畑にはタネが落ちない**（拾えない）。ご当地のタネは下の3つの方法でしか増えない

| | もらえるとき | まける場所 | 位置づけ |
|---|---|---|---|
| 1個目 | **Lv.3 以上**で、その都道府県で初めて「おでかけ」したとき（その県にほかの人の畑が無くてもよい） | **その都道府県だけ** | 旅の記念。かなりレア |
| 2個目 | 1個目をまいた畑が初めて実ったとき（持ち主は遠くから水をやれるので、帰ってからでも育てられる） | どこでも | お土産。地元にまいて近所の人に配る。たくさん出回る |
| 3個目 | 2個目をまいた畑の実が全部収穫されたとき（＝自分も含めて10人に配り終えたとき。4章） | どこでも | やり込み。かなりレア |

- 1個目をその県でしかまけないので、旅行した人の畑がその県に残り、人の少ない県にも少しずつ畑ができる（あとから来る人の訪問先になる）。1個目のご当地ものは、その県に行かないと手に入らない
- 地元で手に入るのは2個目（お土産）だけ

## 4. ご当地の畑（決定）

- **ご当地の実は、その品につき1人1個まで**（その畑で1個ではなく、その品を1個。ほかの人の同じご当地の畑でも、もう持っている品はもらえない）
- すでに持っている人が来たときは、**実は渡さない**（チェックイン・水やりはできる）。これで実10個がちょうど10人のちがう人に行き渡る
- 実ったときの「生産者の取り分」（持ち主に1個）は、10人のうちの1人に数える（持ち主の分は1個だけ）
- **まき直しはできない（1回かぎりの畑）**。まき直しには同じ種類の畑のタネが要り、ご当地のタネはほとんど持っていないため。1個目の畑は実ったら2個目が届き、2個目の畑は配り終えたら3個目が届いて、役目を終える。タネ待ちのまま1週間たつと空き地に戻る（普通の畑と同じ）。地元にご当地の畑が長く残らないので、畑の場所の点でも安全
- 人の少ない県にある1個目の畑は、実が取られきらずに実ったまま残ることがある。それでよい

## 5. 畑の場所を守る（決定）

ご当地の畑は珍しいので、持ち主の ID を畑に入れていなくても、珍しさそのものが手がかりになる（「大田区に北海道のお土産の畑がある → 北海道に行ったあの人は、この近くに住んでいる」「北海道に新しい畑ができた → あの人はいま北海道にいる」）。

- **地図ではご当地の畑を普通の畑と同じ見た目にする**。どの県のものかは、現地でチェックインして初めて分かる。遠くから「北海道の畑はどこか」を探せないようにする
- **まいた畑は、次の日まで全国農地に出さない**（ご当地の畑だけでなく、**普通の畑も**。いまどこにいるかを追えないようにする）。自分の畑は、自分の地図にはすぐ出す。代わりに、トップ画面の自分の畑を押すと、その畑の場所を地図で開けるようにする
  - 「次の日」は、まいてから24時間（dev は時間の進みに合わせて短く）。まき直しでは出し直さない（すでに出ている畑なので）。行を作った日時（`createdAt`。空き地に次の人がまくと作り直される）で数える
  - 画面で出さないだけで、`GameTaneBase` はクライアントから読める（ほかのところと同じく、認可で読めなくするところまではしない）
- 2個目をまくときに「この畑は誰でも訪ねられます。家のすぐ近くは避けるのがおすすめです」と一言出す

## 6. あわせて直すこと

- **飛行機の移動を「位置を偽っている」とみなさない**。いまは時速350kmより速い移動を断る（`geo.ts` の `MAX_SPEED_KMH`）ので、羽田で開いて新千歳で1時間半後に開くと断られる（時速550kmほど。沖縄は600km超）。300km以上離れているときは時速900kmくらいまで認める、前の位置から数時間たっていれば速さを見ない、などにする

## 7. 決めていないこと

- 47都道府県 × 5コースの割り当て表（名産と品の名前）。たたき台を作ってから見直す
- 3個目をもらうのに配る人数（10人）は、遊ぶ人の数を見て変える
- ご当地の集め方の見せ方（日本地図で塗る図鑑、ガーデンの「ご当地の棚」、地方ごとにそろったときのごほうび、など）
