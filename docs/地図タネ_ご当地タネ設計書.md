# うさぽ農園 ご当地タネ 設計書

2026-10-30 の壁打ちで決めた、都道府県ごとの「ご当地もの」の設計。2〜4章と、5章のうちご当地の畑を伏せること・2個目をまくときの一言は 2026-10-30 に作った（9章）。全体のルールは `地図タネ_全体設計書.md`。

## 1. ねらい

- うさぽ農園の中心は「訪ねること」。**そこに行かないと手に入らないもの**があると、旅行やお出かけがそのまま遊ぶ理由になる
- 旅行先で手に入れ、地元に持ち帰って近所の人に配る、という流れで、人とのつながりも広がる
- 47都道府県ぶんそろうと壮観。ただし遊ぶ人の多くは首都圏なので、全部そろう人はまずいない。「旅行に行くたびに1つ増える」くらいの楽しみ方を想定する

## 2. コースの表での位置（決定）

- **各コースの Lv.10 の次に「ご当地」の段を置く**。1つの都道府県につき、コースごとに3つ（1個目・2個目・3個目）。全部で 5コース × 3 × 47 = 705 点
- 拠点の種類としては、コースごとに「ご当地の畑」が1つ（例: 植物コースのご当地の畑）。置かれるものが都道府県で変わる
- 例: 北海道の果樹園＝夕張メロン、神奈川＝湘南ゴールド、田んぼなら各地のブランド米
- **乗り物はその土地ならではの交通**（路面電車・ロープウェイ・ケーブルカー・人力車・渡し船・屋形船・雪上車・水牛車など）。**実在の会社・車両の名前やデザインは使わない**（「路面電車」のような一般的な名前にする）。地域ブランドの名前（夕張メロンなど）は使ってよいが、ロゴやパッケージは描かない
- 量が多いので、はじめは絵文字と名前だけで出し、絵は少しずつ足す。都道府県もそろってから出すのではなく、用意できたところから出してよい
- ID は `local_plant_p01_2` のように、ご当地の畑の ID（`local_<コース>`）・都道府県コード（01〜47）・何個目かを並べる。アイテムは `baseTypeId` を自分で持っているので、ID の形が `${baseTypeId}_${rank}` と混ざってもよい
- ご当地のものには都道府県の印（例: `local: "01"`）を付け、**レベルアップの条件（その種類のタネを全部まく）には入れない**。集めたものの一覧では、レベルの上限（本番 Lv.3）に関係なく出す

## 3. ご当地のタネの手に入れ方（決定）

- **もらえるのは自分のコースのものだけ**
- 1人1都道府県につき、1個目 → 2個目 → 3個目の順に1つずつ。それぞれ1回だけ
- **ご当地の畑にはタネが落ちない**（拾えない）。ご当地のタネは下の3つの方法でしか増えない

| | もらえるとき | まける場所 | 位置づけ |
|---|---|---|---|
| 1個目 | **Lv.3 以上**で、その都道府県で初めて「おでかけ」したとき（その県にほかの人の畑が無くてもよい） | **その都道府県だけ** | 旅の記念。かなりレア |
| 2個目 | 1個目をまいた畑が初めて実ったとき（持ち主は遠くから水をやれるので、帰ってからでも育てられる） | どこでも | お土産。地元にまいて近所の人に配る。たくさん出回る |
| 3個目 | 2個目をまいた畑の実が全部収穫されたとき（＝自分も含めて10人に配り終えたとき。4章） | どこでも | やり込み。かなりレア |

- 1個目をその県でしかまけないので、旅行した人の畑がその県に残り、人の少ない県にも少しずつ畑ができる（あとから来る人の訪問先になる）。1個目のご当地ものは、その県に行かないと手に入らない
- 地元で手に入るのは2個目（お土産）だけ

## 4. ご当地の畑（決定）

- **ご当地の実は、その品につき1人1個まで**（その畑で1個ではなく、その品を1個。ほかの人の同じご当地の畑でも、もう持っている品はもらえない）
- すでに持っている人が来たときは、**実は渡さない**（チェックイン・水やりはできる）。これで実10個がちょうど10人のちがう人に行き渡る
- 実ったときの「生産者の取り分」（持ち主に1個）は、10人のうちの1人に数える（持ち主の分は1個だけ）
- **まき直しはできない（1回かぎりの畑）**。まき直しには同じ種類の畑のタネが要り、ご当地のタネはほとんど持っていないため。1個目の畑は実ったら2個目が届き、2個目の畑は配り終えたら3個目が届いて、役目を終える。タネ待ちのまま1週間たつと空き地に戻る（普通の畑と同じ）。地元にご当地の畑が長く残らないので、畑の場所の点でも安全
- 人の少ない県にある1個目の畑は、実が取られきらずに実ったまま残ることがある。それでよい

## 5. 畑の場所を守る（決定）

ご当地の畑は珍しいので、持ち主の ID を畑に入れていなくても、珍しさそのものが手がかりになる（「大田区に北海道のお土産の畑がある → 北海道に行ったあの人は、この近くに住んでいる」「北海道に新しい畑ができた → あの人はいま北海道にいる」）。

- **ほかの人のご当地の畑は、何の畑かを伏せる**（2026-10-30 に「同じ見た目」から変えた）。地図では、育っているあいだは普通の畑と同じ絵で、実っても実の絵の代わりに「？」を出し、タップしても「なぞの畑」とだけ出す。現地でも、**実るまではチェックインしても何の畑か分からない**（実ってからチェックインすると分かる）。珍しい畑があること自体は分かるが、どこの県のものかは遠くから探せない。持ち主には自分の畑はそのまま見える
- **まいた畑は、次の日まで全国農地に出さない**（ご当地の畑だけでなく、**普通の畑も**。いまどこにいるかを追えないようにする）。自分の畑は、自分の地図にはすぐ出す。代わりに、トップ画面の自分の畑を押すと、その畑の場所を地図で開けるようにする
  - 「次の日」は、まいてから24時間（dev は時間の進みに合わせて短く）。まき直しでは出し直さない（すでに出ている畑なので）。行を作った日時（`createdAt`。空き地に次の人がまくと作り直される）で数える
  - 画面で出さないだけで、`GameTaneBase` はクライアントから読める（ほかのところと同じく、認可で読めなくするところまではしない）
- 2個目をまくときに「この畑は誰でも訪ねられます。家のすぐ近くは避けるのがおすすめです」と一言出す

## 6. あわせて直すこと

- **飛行機の移動を「位置を偽っている」とみなさない**。いまは時速350kmより速い移動を断る（`geo.ts` の `MAX_SPEED_KMH`）ので、羽田で開いて新千歳で1時間半後に開くと断られる（時速550kmほど。沖縄は600km超）。300km以上離れているときは時速900kmくらいまで認める、前の位置から数時間たっていれば速さを見ない、などにする

## 7. ご当地のもの（たたき台、2026-10-30）

定義は `src/lib/game/chizuTane/localItems.ts`（`TANE_ITEMS` とは別なのでレベルの条件には入らないが、`TANE_ITEM_BY_ID` では引ける）。管理画面 `/admin/chizu-tane/items` の下に表で出る。まず7都道府県ぶんを作った（ほかの40県では、まだ何ももらえない）。

### 7.1 3つの役目（決定）

旅の流れに合わせる。手に入れ方（3章）とも合う（1個目は現地でしか出回らず、2個目がいちばん多くの人に行き渡る）。

| | 役目 | 植物 | 動物 | 趣味 | 乗り物 | 建物 |
|---|---|---|---|---|---|---|
| 1個目 | **現地で**味わう・乗る・体験する | 現地で食べるとれたてのもの | 現地で食べる名物の魚・牛 | 現地で体験する工芸 | 現地で乗る地元の足 | 現地グルメ |
| 2個目 | **お土産**として持ち帰る | 持ち帰る果物・お茶 | お土産になる生きもの（下） | お土産の工芸品・郷土玩具 | 旅の思い出になる名物の乗り物 | お土産の名物 |
| 3個目 | 手に入れて**見せたい**（ガーデンに飾る） | 名所の花・名木 | 立派な・珍しい生きもの | 大きく立派な工芸品・飾り | 祭りの山車など | 名所の建物・神社 |

- 3個目は「レアなもの」ではなく「見せたいもの」
- 建物はふつうの種類と同じ「小物 → 小物 → 建物」の並びになる
- **動物の2個目**は次のどれか: (1) お土産・グッズの絵柄になる生きもの（上野のパンダ・シマエナガ）、(2) 神社のお使いで、お守り・縁起物として持ち帰るもの（鶴岡八幡宮の鳩・太宰府のうそ・三峯のオオカミ・こんぴら狗・奈良の鹿）、(3) 持ち帰って飼える生きもの（大和郡山の金魚・新潟の錦鯉など）
- 乗り物は交通だけでは足りない県があるので、祭りの山車・その土地らしいはたらく乗り物も入れる

### 7.2 名前の決め方（決定）

- **地名を付ける**（箱根の登山電車、長瀞のアユ）。ふつうの品（登山電車・カワセミ…）と区別でき、どこのものかも分かる
- **実在の名所・神社は使ってよい**（時計台・雷門・熊本城・金刀比羅宮など）。絵はそっくりにせず、それらしく描く
- 会社の商品名・会社や車両の名前は使わない（白い恋人 → バターサンド、江ノ電 → 海辺の路面電車、海賊船は使わない）。地域ブランド（夕張メロン・あまおう・デコポン・湘南ゴールド）は使ってよい（2章）

## 9. 作ったもの（2026-10-30）

- もらった記録は `GameTaneLocalGrant`（ユーザー×都道府県。`firstAt`・`secondAt`・`thirdAt`）。本人だけ読める
- 1個目: おでかけの画面に、その県で初めてのときだけ「ご当地のタネをもらう」ボタンを出す（Lv.3 未満なら「Lv.3 になるともらえる」とだけ出す）。押すと `claimLocalTaneSeed`（`chizu-tane-seeds`）が位置から県を判定し直し、レベル（`GameTanePlayer.grantedLevel`）を確かめて渡す。行を作るのは「無いときだけ」なので2回は渡らない。案のある県に「行ったことがある」だけでは記録しないので、あとから案を足した県でも、次に行けばもらえる
- まく（`chizu-tane-place`）: 1個目はその県の地区でしかまけない。2個目・3個目はどこでもまけ、画面で「家のすぐ近くは避けるのがおすすめ」と出す。まき直しは断る
- チェックイン（`chizu-tane-checkin`）: ご当地の実は、まだ持っていない人だけがもらえる（`takeFruit` の `once`。実の行が無いときだけ書く）。もう持っている人には `have` を返し、実は残す。生産者の取り分も同じ扱い。タネは落ちない。1個目の畑が実ったら（現地でも遠くからの水やりでも）2個目、2個目の畑の実が全部収穫されたら3個目のタネを持ち主に渡す（`grantNextLocalSeed`）。ほかの人が実らせた・取りきったときは、持ち主への通知に書く
- ご当地の実は、どのコースの人でももらえる（もらえるタネが自分のコースのものだけ）。ご当地の畑に初めて来たのも訪問（レベル）に数え、まいた地区も開拓した地区（ガーデン）に数える。実はガーデンに飾れる
- 集めたものの画面では、持っているご当地のものを下に都道府県ごとに出す（日本地図の図鑑などの見せ方は8章のとおりまだ）
