# うさぽ農園 ご当地の乗り物 見直し案（2026-11-03）

ご当地のもののうち、乗り物コースの3つを見直す案。決まったら `src/lib/game/chizuTane/localItems.ts` を直し、`art/chizu-tane/redo.md` の「ものを替えた」に足して描き直す。

## 見直す理由

- **2個目（お土産）が、現地でしか乗れない乗り物になっている**（角館の人力車・蔵王の雪上車など）。持ち帰るお土産なので、**乗り物にまつわるお土産品**（模型・おもちゃ・記念きっぷ・ヘッドマーク・郷土玩具など）にする
- **3個目（記念品）が祭りの山車・屋台に偏っている**（47のうち30ほど）。ガーデンに飾って見せたい**立派な乗り物**（保存されている名車・観光列車・名物の船・ロケットなど）を中心にし、祭りはとくに有名なものだけ残す
- 2026-11-03 から、実在の会社・車両の名前も使ってよい

## 決め方

| | 役目 | 乗り物で描くもの |
|---|---|---|
| 1個目 | 現地で乗る | その土地で乗れる名物の乗り物（いまのものをおおむね残す） |
| 2個目 | お土産 | 乗り物にまつわるお土産品。同じ種類が続かないよう、模型・おもちゃ・ミニカー・記念きっぷ・ヘッドマーク・ペーパークラフト・郷土玩具をまぜる |
| 3個目 | 記念品 | 飾って見せたい立派な乗り物。祭りの山車は、とくに有名なもの（ねぶた・祇園祭・高山祭・岸和田・博多山笠など）だけ |

- キャラクターのもの（アンパンマン列車・トーマスなど）は、絵が描きにくいので入れない
- ★ は、事実（いまも走っているか・その県のものか）を確かめたいもの

## 兵庫から先の案の考え方（2026-11-04）

決まった行の傾向に合わせて、兵庫から沖縄の案を作り直した（まだ ✅ ではない）。

- 実在の名前のついた列車・船を使う。3個目は、背景や場面を添えて「その土地らしさ」を出す（樹氷・転車台・紅葉・USJ のように）
- 2個目は、実在の列車のプラレール・おもちゃ・模型をまぜる。同じ県の1個目と同じものは避ける
- 祭りは、その県を代表するもの（ホーランエンヤ・ちょうさ・よさこい・博多祇園山笠・唐津くんち・ハーリー）だけ残す
- キャラクターのもの（アンパンマン列車・鬼太郎列車など）は入れない
