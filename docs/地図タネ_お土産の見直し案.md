# うさぽ農園 ご当地のお土産（2個目） 見直し案（2026-11-04）

ご当地のもののうち、2個目（お土産）の植物・動物・趣味・建物を見直す案（乗り物は `地図タネ_乗り物の見直し案.md` で見直し済み）。決まったら `src/lib/game/chizuTane/localItems.ts` を直す。2個目はまだ絵が無いので、描き直しは要らない。

## 見直す理由

- **同じ県で、同じものが2回出ている**: 青森のりんご（植物）とアップルパイ（建物）、岩手の南部鉄器（1個目の風鈴づくりと2個目の鉄瓶）
- **同じ種類が多い**: 建物のせんべい（6）・もち・だんご（11）、植物のお茶（7）、趣味の彫りや漆のお盆（日光彫・鎌倉彫・村上の木彫堆朱・紀州漆器）、お面（なまはげ・石見神楽・高千穂の神楽面）。ならべると見分けにくい
- **植物・動物が、作物や生きものそのものになっている**。お土産なので、加工品やぬいぐるみなどの品物にする（2026-11-04 に決めた）
- **建物（お土産の名物）に駅弁を入れる**: 釜・カニの甲羅・牛の顔の箱など、器そのものに特徴があって見分けやすい。旅のお土産にも合う（富山のますのすしは、もう駅弁）
- 2026-11-03 から、実在の名前を使ってよい

## 決め方

| コース | 2個目で描くもの |
|---|---|
| 植物 | **作物を使った加工品**（ジュース・ゼリー・お菓子・干したもの・漬物など。2026-11-04 に決めた）。お茶はかぶるので、残すものは見た目を分ける（狭山茶は升に盛った茶葉、静岡茶は湯のみ、西尾は抹茶と茶筅、宇治は茶壺、嬉野は丸まった玉の茶葉と急須） |
| 動物 | **生きものにちなんだお土産品**（ぬいぐるみ・置物・加工品など。生きた姿ではなく品物として。2026-11-04 に決めた） |
| 趣味 | お土産の工芸品・郷土玩具。同じ種類が続かないように |
| 建物 | お土産の名物と駅弁。駅弁は、ふたを開けた器ごと描く（「箱や包み紙は描かない」の例外） |

- **絵は5列×3行で15点ずつ頼む**（1行が1都道府県。北海道〜岩手、宮城〜山形…の3県ずつ。シートは `local-2-p01-03` など）。同じシートに入る3県で、似たものが並ばないようにする
- ★ は、事実（いまも売っているか・よく知られているか）を確かめたいもの
- ⚠ は、替えるかどうか迷うもの

## 替える理由（ひとこと）

- 北海道 バターサンド → いかめし: クッキーの類（丸ぼうろ・ちんすこう）とかぶる。いかめしは森駅の駅弁（決まった）
- 青森 八幡馬 → 金魚ねぶた: 福島の三春駒と同じ木の馬になるため。金魚ねぶたは、ねぶた祭りの小さな金魚の灯籠で、お土産の定番（決まった）
- 青森 アップルパイ → 津軽めんこい懐石弁当 ひとくちだらけ: 植物のりんごとかぶるため。ひとくちずつのおかずが並ぶ駅弁（決まった）
- 岩手 南部鉄器の鉄瓶 → 南部鉄器の急須: 1個目が南部鉄器の風鈴づくりなので秀衡塗のお椀を案にしたが、南部鉄器のまま急須にした（決まった）
- 宮城 いちご・スズメ・ずんだもち → ずんだシェイク・笹かまぼこ・萩の月: いちごはほかの県にも多いので組み直した（決まった。仙台の曲がりねぎも候補）
- 秋田 あきたこまち: 新潟の1個目（魚沼のコシヒカリの新米）と似ないよう、小さな米俵にする（決まった）
- 福島: 植物・動物を品物にし、三春駒を動物に移して趣味を起き上がり小法師に。まんじゅうが多いので、ままどおるに（決まった）。あんぽ柿は山梨の枯露柿と同じ干し柿なので、山梨で枯露柿を替える
- 茨城: 栗は多いので干しいもに、鹿は奈良とかぶるのでシロワニのぬいぐるみに、結城紬は絵で分かりにくいので水戸黄門の印籠に（決まった）
- 千葉: 建物のぬれせんべいが乗り物の2個目（銚子電鉄のぬれ煎餅）とかぶっていたので、ぴーなっつ最中に。動物は牛乳を使ったミルクラングドシャに（決まった）
- 栃木 日光彫 → 黄ぶな: 彫りのお盆が多いため。宇都宮の、黄色い魚の郷土玩具（決まった）
- 群馬 磯部せんべい → 峠の釜めし: せんべいが多いため。益子焼の釜に入った、横川駅の駅弁（決まった）
- 神奈川 シューマイ → シウマイ弁当: 崎陽軒の駅弁。シウマイと俵のごはん
- 福井 羽二重もち → 越前かにめし: もちが多いため。カニの甲羅の形の器の駅弁
- 山梨 甲州のきなこもち → 桔梗信玄餅: 実在の名前にする（きなこと黒蜜のもち）
- 愛知 名古屋のえびせんべい → 天むす: せんべいが多いため
- 三重 伊勢茶 → 赤福餅: お茶が多いため。伊勢いもを案にしたが、加工品にならないので赤福に（決まった）
- 三重 松阪牛のしぐれ煮 → モー太郎弁当: 牛の顔の形の箱の、松阪駅の駅弁（すき焼き）
